Властивість float

Блок float: left

Текст обтікає плаваючий блок зліва. Якщо тексту багато, він плавно переходить під сам блок після заповнення вільного місця. Властивість float раніше активно використовувалася для верстки колонок, але зараз частіше застосовується для зображень у тексті.

FAQ / Спойлери

CSS — це мова стилів, яка відповідає за зовнішній вигляд та оформлення HTML-документа.
Float зміщує елемент вліво або вправо, дозволяючи текстовому вмісту обтікати його.
Fixed зафіксований відносно екрана браузера при прокрутці, а Absolute позиціонується відносно найближчого батьківського елемента.
